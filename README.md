# 🌙 SleepWell AI
### Analisis Kualitas Tidur untuk Peningkatan Produktivitas dan Well-being

SleepWell AI adalah aplikasi berbasis *Artificial Intelligence* yang dirancang untuk membantu pengguna memantau, menganalisis, dan meningkatkan kualitas tidur mereka melalui pendekatan berbasis data.

Proyek ini dikembangkan secara tim dalam program **Coding Camp 2026 powered by DBS Foundation** dengan tema **Healthy Lives & Well-being**, oleh Tim **CC26-PSU283**.

> 🔗 **Repository asli tim (lengkap dengan source code full-stack):** [github.com/albanysiswanto/sleepwell](https://github.com/albanysiswanto/sleepwell)
>
> Folder ini merupakan bagian **Data Science** dari proyek SleepWell AI, di-mirror/disalin ke repo portofolio pribadi untuk keperluan submission Coding Camp 2026 (MBKM).
