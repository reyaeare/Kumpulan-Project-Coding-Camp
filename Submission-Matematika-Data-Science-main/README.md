# Submission-Matematika-Data-Science
# Belajar Matematika untuk Data Science

## Deskripsi Project

Project ini merupakan submission akhir kelas **Belajar Matematika untuk Data Science**.
Submission berfokus pada penerapan konsep probabilitas, statistika, distribusi data, algoritma Naive Bayes, dan A/B Testing menggunakan Python.

Pada project ini, dilakukan penyelesaian beberapa studi kasus yang berkaitan dengan:

* Distribusi statistik
* Algoritma Naive Bayes
* Sistem rekomendasi berbasis A/B Testing
* Evaluasi software development menggunakan A/B Testing

Semua implementasi dilakukan tanpa menggunakan library otomatis seperti scikit-learn untuk memastikan pemahaman konsep matematika dan statistika secara mendalam.
